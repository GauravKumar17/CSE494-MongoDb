# Neighbourly

### Cooperative Gig Services Platform for Household and Community Services

Neighbourly is a Django and MongoDB web application that connects customers with local service providers such as electricians, plumbers, painters, cleaners, carpenters and appliance technicians.

The project makes local service booking easier while demonstrating practical MongoDB concepts, including CRUD operations, document relationships, indexing, validation and aggregation.



## About the Project

Finding a skilled local worker often depends on personal contacts and scattered listings. Neighbourly provides a common platform where customers can discover workers, explore their skills and request a service.

Workers can create service profiles, manage their availability and accept or decline requests. Administrators review worker profiles and monitor platform activity.

The application also supports bookings for shared community spaces and connects its purpose with the United Nations Sustainable Development Goals.
